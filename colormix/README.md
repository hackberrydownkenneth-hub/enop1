# 🎨 カラー剤 計算機 / 染髮劑計算機

美容師さんがカラー剤を調合するときの計算を、**タップだけ**で終わらせるアプリです。
インストール不要・オフラインで動きます（`colormix/index.html` をブラウザで開くだけ）。

**日本語 / 廣東話（香港・繁体字）** に対応しています。

## できること

### 1. 合計量から計算（メイン）

「ぜんぶで 90g つくりたい」と入れるだけで、**1剤それぞれのグラム数**と**2剤の量**が出ます。

- 2剤のわりあいは **1:1 / 1:1.5 / 1:2 / 1:3**、それ以外の倍率も入力できます
- 1剤は何種類でもミックスOK（例 ブラウン 2 : マット 1）
- 割合を変えると、各1剤のグラム数がその場で切り替わります

### 2. 1剤の量から計算

「ブラウンを 30g、マットを 10g 使う」と入れると、**2剤の量と仕上がりの合計量**が出ます。

### 言語切り替え

画面上部のボタンで **日本語 ⇄ 廣東話** をいつでも切り替えられます。
初回は端末の言語設定から自動で選ばれ（`zh-*` / `yue-*` なら廣東話）、以降は選んだ言語を記憶します。

広東語表示では香港のサロンで使う言い方に合わせています。

| 日本語 | 廣東話 |
|--------|--------|
| 1剤 | 染膏 |
| 2剤（オキシ） | 雙氧奶（二劑） |
| 合計量 | 總份量 |
| わりあい | 比例 |
| はかる量 | 要秤幾多 |

### そのほか

- **1g刻み / 0.1g刻み** を切り替え（サロンの秤に合わせて）
- **レシピ保存** — よく使う配合に名前をつけて保存（端末内に保存されます）
- **コピー** — 計算結果をテキストでコピーしてスタッフに共有
- スマホ縦持ち前提の大きなボタン・大きな数字。ダークモード対応

## 計算式

```
1剤の合計 ＝ 合計量 ÷ (1 ＋ 2剤の倍率)
2剤       ＝ 合計量 － 1剤の合計
各1剤     ＝ 1剤の合計 × その割合 ÷ 割合の合計
```

例）合計 90g・1:2 の場合 → 1剤 30g、2剤 60g。
1剤を ブラウン 2 : マット 1 でまぜるなら、ブラウン 20g・マット 10g。

割り切れないときは秤の刻みに合わせて丸めますが、**端数は最大剰余方式で配分**するので

- 各1剤のグラム数の合計は 1剤の合計と必ず一致
- 1剤＋2剤は入力した合計量と必ず一致

します（例：合計 100g・1:2・1剤3種等分 → 11g + 11g + 11g、2剤 67g、合計ちょうど 100g）。

## 使い方

### パソコン・スマホでそのまま開く

`colormix` フォルダごと端末にコピーして、`index.html` をブラウザで開きます。
スマホなら「ホーム画面に追加」しておくとアプリのように使えます。

### 1ファイルで配る

`standalone.html` は CSS / JS を全部埋め込んだ1ファイル版です。
このファイルだけをスタッフに送れば、開くだけで同じアプリが動きます。

```bash
# index.html / style.css / *.js を編集したら作り直す
node colormix/build.js
```

### ローカルサーバーで開く（社内の共有端末など）

```bash
python3 -m http.server 8000 --directory colormix
# → http://localhost:8000
```

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `index.html` | 画面 |
| `style.css` | 見た目（ダークモード対応） |
| `calc.js` | 配合計算ロジック（画面から独立した純粋関数） |
| `i18n.js` | 画面の文言（日本語 / 廣東話） |
| `app.js` | 入力・表示・保存の制御 |
| `calc.test.js` | 計算ロジックのテスト |
| `build.js` | 1ファイル版を生成するスクリプト |
| `standalone.html` | 配布用の1ファイル版（`build.js` が生成） |

## テスト

```bash
node --test colormix/calc.test.js
```

外部ライブラリは使っていません（Node 18 以降の標準テストランナーのみ）。

## 文言を足すとき

`calc.js` は UI 文言を持たず、エラーは `need_total` のような**コード**だけを返します。
表示する文言はすべて `i18n.js` の辞書にあるので、言語を足すときは

1. `i18n.js` に辞書オブジェクトを追加して `order` に言語コードを入れる
2. `detect()` に判定を足す

の 2 手順で済みます。日本語と広東語のキーが揃っているかは次で確認できます。

```bash
node -e '
const I = require("./colormix/i18n.js");
const ja = Object.keys(I.dictionaries.ja);
const yue = Object.keys(I.dictionaries.yue);
console.log(ja.filter(k => !yue.includes(k)), yue.filter(k => !ja.includes(k)));
'
```
