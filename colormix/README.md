# 🎨 カラー剤 計算機

美容師さんがカラー剤を調合するときの計算を、**タップだけ**で終わらせるアプリです。
インストール不要・オフラインで動きます（`colormix/index.html` をブラウザで開くだけ）。

## できること

### 1. 合計量から計算（メイン）

「ぜんぶで 90g つくりたい」と入れるだけで、**1剤それぞれのグラム数**と**2剤の量**が出ます。

- 2剤のわりあいは **1:1 / 1:1.5 / 1:2 / 1:3**、それ以外の倍率も入力できます
- 1剤は何種類でもミックスOK（例 ブラウン 2 : マット 1）
- 割合を変えると、各1剤のグラム数がその場で切り替わります

### 2. 1剤の量から計算

「ブラウンを 30g、マットを 10g 使う」と入れると、**2剤の量と仕上がりの合計量**が出ます。

### そのほか

- **1g刻み / 0.1g刻み** を切り替え（サロンの秤に合わせて）
- **レシピ保存** — よく使う配合に名前をつけて保存（端末内に保存されます）
- **コピー** — 計算結果をテキストでコピーしてスタッフに共有
- スマホ縦持ち前提の大きなボタン・大きな数字。ダークモード対応

## 計算式

```
1剤の合計 ＝ 合計量 ÷ (1 ＋ 2剤の倍率)
2剤       ＝ 合計量 － 1剤の合計
各1剤     ＝ 1剤の合計 × その割合 ÷ 割合の合計
```

例）合計 90g・1:2 の場合 → 1剤 30g、2剤 60g。
1剤を ブラウン 2 : マット 1 でまぜるなら、ブラウン 20g・マット 10g。

割り切れないときは秤の刻みに合わせて丸めますが、**端数は最大剰余方式で配分**するので

- 各1剤のグラム数の合計は 1剤の合計と必ず一致
- 1剤＋2剤は入力した合計量と必ず一致

します（例：合計 100g・1:2・1剤3種等分 → 11g + 11g + 11g、2剤 67g、合計ちょうど 100g）。

## 使い方

### パソコン・スマホでそのまま開く

`colormix` フォルダごと端末にコピーして、`index.html` をブラウザで開きます。
スマホなら「ホーム画面に追加」しておくとアプリのように使えます。

### ローカルサーバーで開く（社内の共有端末など）

```bash
python3 -m http.server 8000 --directory colormix
# → http://localhost:8000
```

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `index.html` | 画面 |
| `style.css` | 見た目（ダークモード対応） |
| `calc.js` | 配合計算ロジック（画面から独立した純粋関数） |
| `app.js` | 入力・表示・保存の制御 |
| `calc.test.js` | 計算ロジックのテスト |

## テスト

```bash
node --test colormix/calc.test.js
```

外部ライブラリは使っていません（Node 18 以降の標準テストランナーのみ）。
